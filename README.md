# React Forms

Навчальний React-проєкт для демонстрації контрольованої та неконтрольованої форм.

## Що реалізовано

- контрольована форма з полями імені, пароля та email;
- неконтрольована форма з полями імені користувача та коментаря;
- обробка відправлення форм через `onSubmit`;
- виведення даних у консоль;
- очищення полів після відправлення;
- початковий loader із затримкою `2000 мс`;
- fallback для `Suspense`;
- адаптивний дизайн для desktop і mobile;
- окремий файл стилів `App.css`.

## Структура проєкту

```text
src/
├── components/
│   ├── App.tsx                 # Кореневий компонент застосунку
│   ├── Root.tsx                # Loader, Suspense і сторінка з формами
│   ├── ControlledForm.tsx      # Контрольована форма
│   ├── UncontrolledForm.tsx    # Неконтрольована форма
│   └── Loader.tsx              # Компонент індикатора завантаження
├── helpers/
│   └── delay.ts                # Допоміжна функція для затримки
├── App.css                     # Усі стилі застосунку
└── main.tsx                    # Точка входу React-застосунку
```

## Запуск проєкту

Встановити залежності:

```bash
npm install
```

Запустити dev-сервер:

```bash
npm run dev
```

Виконати production-збірку:

```bash
npm run build
```

Перевірити код lint-перевіркою:

```bash
npm run lint
```
